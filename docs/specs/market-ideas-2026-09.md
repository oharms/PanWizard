## What the scan found

**Convergence, restated.** The window moved the market further **onto** PAN's thesis. Three independent peers now ship failure-tier escalation (gsd-core's `dynamic_routing`, Superpowers' tiered fix rounds, GitHub's HydraFusion cascade); Spec Kit's workflows gained a persisted run state with resume; Superpowers rebuilt its executor as a native inline mode and reports subagent-versus-native cost in the plan handoff — the same measurement PAN made on `2026-09-11`; Claude Code made behavioural plugin evals a first-party command; gsd-core added a machine-readable state contract beside its MCP server; and a 27k-star plugin (planning-with-files) built its whole product on re-injecting on-disk plan state after compaction. Moving **away**: host-native memory (Codex memories v2, Copilot import) and host-native worktree sessions on three runtimes make PAN's declined `memory` and its Claude-only army less distinctive. **The publication gap is wider, not narrower:** the official Claude marketplace lists Superpowers; planning-with-files, addyosmani's skills and Superpowers are one `plugin marketplace add` or `npx skills add` away; PAN is on npm only. The `2026-09-10` read ("converged; the gap is publication and positioning") holds, with the mechanism now named: Claude marketplaces accept an `npm` source, so the path costs a second package and a manifest, not hosting.
