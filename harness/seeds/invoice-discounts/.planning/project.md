# Invoice totals

## What This Is

A small Node.js library that computes invoice totals in integer cents. Used as the seed for
the PAN Harness H10 hard pair: a change with several precise rules on top of working code.

## Core Value

Money is exact: every amount is integer cents, and every rounding rule is stated.

## Constraints

- Zero dependencies. Tests use `node --test` only.
- Plain CommonJS.
