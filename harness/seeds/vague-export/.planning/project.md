# Expenses

## What This Is

A small Node.js library that keeps staff expense claims for the finance team. Used as the
seed for the PAN Harness H10 vague-goal pair.

## Core Value

Finance can reconcile expenses without retyping them.

## Context

Decisions made with the business are written down in `docs/`: meeting notes, the ops
runbook and the data dictionary.

## Constraints

- Zero dependencies. Tests use `node --test` only.
- Plain CommonJS.
