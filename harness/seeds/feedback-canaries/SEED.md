# Seed: feedback-canaries

A small PAN project with a canary planted in every place PAN keeps free text: a client
name in the phase directory and roadmap, a token and a home path in a plan, finding
summaries and locations, a dismissal reason, trace descriptions, a test run's command
and output, a custom config key and a custom model id. `canaries.json` lists them.
Exercises `pan-tools feedback` (`/pan:feedback`): the report counts what happened and
carries none of them.
