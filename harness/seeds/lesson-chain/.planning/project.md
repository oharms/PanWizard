# Greetings library

## What This Is

A small Node.js library of message functions: `greet(name)` and `farewell(name)`. It is a fixed seed for PAN's behavioural harness.

## Core Value

Every plan has one observable outcome, a function and its test, so a run either produced the artifact or it did not.

## Constraints

- Zero dependencies. Tests use `node --test` only.
- Plain CommonJS.
