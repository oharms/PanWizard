Shopkeep is a small zero-dependency Node library that keeps a corner shop's stock and orders in one JSON file: expose `createShop(file)` from `src/shop.js`, where a missing file is an empty shop, every change is saved at once, and a shop reopened on the same file after a restart sees exactly the same products, reservations, orders and shipments. Money is always integer cents and quantities are positive whole numbers; anything else, an unknown SKU or an unknown order id throws an error. `addProduct({ sku, name, priceCents, stock, lowStockThreshold })` adds a product (stock may be 0, the threshold defaults to 0, and a duplicate SKU throws), `restock(sku, qty)` adds stock, and `getProduct(sku)` returns `{ sku, name, priceCents, stock, reserved, available }`, where available is stock minus reserved. `placeOrder([{ sku, qty }], date)` reserves stock for every line and returns `{ id, status: 'open', totalCents }`, with ids counting from 1 and never reused; if any line asks for more than is available, the whole order is refused with an error and nothing is reserved. `fulfil(id, sku, qty, date)` ships part or all of a line, taking it out of both stock and reserved: the status becomes `partial`, then `fulfilled` once every line has shipped, and shipping more than a line still needs throws. `cancel(id)` marks an order `cancelled` and releases only the reservations not yet shipped; a fulfilled or cancelled order can be neither cancelled nor shipped, and `getOrder(id)` returns `{ id, status, totalCents }` as it now stands. `lowStock()` lists `{ sku, available }` for every product whose available count is at or below its threshold, by SKU ascending. `dailyReport(date)` returns text: `Report <date>`, then one line per product by SKU ascending, `<sku>: shipped <units>, revenue <amount>, available <n>`, with ` LOW` appended when the product is low, then `Total revenue <amount>`, counting only shipments made on that date at the product's price, amounts in currency units with two decimals, lines joined by `\n`.
